About ProcessX

An educational tool that shows how an operating system decides which process gets the CPU. All scheduling maths runs in Python (Flask); the browser only draws the results.

How the numbers are calculated

Completion time (CT)
When the process finishes.
Turnaround time (TAT)
CT − arrival time.
Waiting time (WT)
TAT − burst time.
Response time (RT)
First time on the CPU − arrival time.
CPU utilization
Busy time ÷ total execution time × 100.

Conventions used

  • Priority: a smaller number means higher priority (1 is the most urgent).
  • Ties: shorter job or higher priority first, then earlier arrival, then the order you entered the processes.
  • Round Robin: a process that arrives while another is running joins the queue before the interrupted process goes back.
  • The timeline starts at 0. Gaps with nothing to run are shown as idle time.
  • Consecutive time slices of the same process are drawn as one block.
